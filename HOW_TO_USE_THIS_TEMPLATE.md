# How to use this starter template

1. Create a new private Git repo for your micro-project and copy these files
   into it (keep the folder structure).
2. Set up your DDEV project in the same repo (`ddev config`, then install
   Drupal or your stack as the task requires).
3. Fill in CLAUDE.md first — the agent works much better with project rules.
   Copy or symlink it to AGENTS.md or .cursor/rules if you use another tool.
4. Work through the docs in order: research → docs/ADR-001.md,
   plan → docs/PLAN.md, then build, keeping docs/AI_LOG.md up to date as you
   go and saving transcripts in transcripts/.
5. Finish with README.md (install + run in under 5 minutes) and docs/RETRO.md.
6. Delete this file and all <placeholder> text before the demo.
