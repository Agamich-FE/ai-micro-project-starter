# Agent transcripts

Save exported agent sessions here as you go (don't wait until the end —
sessions can be lost).

- Claude Code: run `/export` in the session and save the file here.
- Other tools: export the chat if possible, otherwise add screenshots.

Name files by date and phase, e.g. `2026-11-10-research.md`,
`2026-11-11-build-webhook.md`.

Before committing, check transcripts for secrets (API keys, passwords,
tokens) and remove them.
